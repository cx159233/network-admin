## 一、数字应用管理

### 1. 定义

数字应用管理负责纳管面向医疗卫生机构与医技护人员交付的数字化应用（如 HIS、LIS、PACS、家庭医生签约等业务应用系统）。每个数字应用记录应用名称、系统地址、服务商与合作方联系方式、服务对象及应用覆盖范围等信息，经征集审核后上架至服务目录，供机构订阅开通使用。

## 三、基础服务管理

### 1. 定义

基础服务管理负责纳管平台底层的云资源类基础服务（计算、存储、网络、数据库等）。每个基础服务通过"服务专区 + 服务分类"标签进行归类（服务专区、服务分类仅为该类数据内部的分类标签字段），并记录部署云服务商等信息，为上层数字应用与能力组件提供资源供给支撑。

### 2. 字段说明

| 字段（具体命名以接口文档为准） | 中文名 | 类型 | 必填 | 说明 / 取值 |

| serviceName | 基础服务名称 | String | 是 | 最长 40 字符 |

| description | 服务描述 | String | 是 | 最长 500 字符 |
| paymentMethodRef | 付费方式参考 | String | 否 | 最长 200 字符 |
| serviceProvider | 服务商名称 | String | 否 | — |
| contactName1 / contactPhone1 | 联系人1姓名/电话 | String | 否 | — |
